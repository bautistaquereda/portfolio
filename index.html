about_me.md

[ BACK-END ]

Building RESTful APIs with Java, Spring Boot and Spring MVC, and with Node.js. Applying object-oriented programming (OOP) and design patterns, with code organized in a layered architecture (controllers, services, data access). Implementing authentication and authorization with Spring Security, input validation and consistent HTTP responses and error handling. Working with MySQL and SQL for data persistence: table design, queries and integration with the application. Building microservices with Spring Cloud (API Gateway, Load Balancer, Circuit Breaker), asynchronous messaging with RabbitMQ, security with OAuth 2.0 / OpenID Connect on Keycloak, NoSQL databases with MongoDB and services in Go.

[ FRONT-END ]

Building interfaces with JavaScript, HTML5, CSS3 and React: responsive design, form validation, CRUD applications and third-party API integration. Working from designs and prototypes in Figma, and using Miro for diagrams and planning.

[ WORKFLOW ]

Version control with Git and GitHub: feature branches and small, descriptive commits. Working under Agile / Scrum (sprints, dailies, retrospectives), organizing tasks in Trello and communicating through Slack. Testing endpoints with Postman and writing automated API tests with RestAssured. Applying DevOps and cloud computing on AWS: deployments on Kubernetes with GitOps (Argo CD) and CI/CD pipelines with Jenkins.
